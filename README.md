# IRIS — Intelligent Root-cause Identification System

## Project Title & Description
IRIS is a Windows-based System Slowdown Diagnosis Tool that continuously monitors
low-level system performance metrics, builds a machine-specific baseline, and
correlates multiple performance indicators to identify the probable root cause of
a PC slowdown — presenting the result and a fix in plain, non-technical language.
